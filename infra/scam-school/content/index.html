Scam School — Interactive Lessons

This is the static host for H5P interactive lessons authored in Lumi (desktop) and exported as standalone HTML.

No lessons are published yet. Export each lesson from Lumi via File → Export → All-in-one HTML and drop the file into infra/scam-school/content/ on the host, e.g.: 

mv ~/Lumi/rug-pull-red-flags.html /srv/work/repos/rmi-backend/infra/scam-school/content/

The lesson is then reachable at http://127.0.0.1:8091/<filename> and can be linked or iframe-embedded from a CourseLit lesson. See infra/scam-school/README.md → "Authoring H5P lessons with Lumi".

This placeholder page is served by nginx from ./content (read-only mount).
